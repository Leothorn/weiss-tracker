# Contributing

Bug reports and improvements are welcome. Never put real assessment answers, exports, names or other personal health information in issues, screenshots, logs or pull requests. Use synthetic examples.

Run `pnpm install --frozen-lockfile`, `pnpm typecheck` and `pnpm test` before submitting changes. Check both mobile layouts and storage failure behavior when changing assessment flows.

Contributions to original app code are submitted under PolyForm Noncommercial 1.0.0. Questionnaire content is separately copyrighted; do not change its wording, translate it or represent modified scoring as validated without the appropriate authorization and evidence.
